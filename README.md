## 🚀 ¿Cómo Empezar?

### Paso 1: Clonar este Repositorio
```bash
git clone https://github.com/RafaelAlbaG/Mi-Viaje-Python-con-GitHub.git
cd Mi-Viaje-Python-con-GitHub
```

### Paso 2: Leer el Manual de GitHub Desktop
Abre `MANUAL_GITHUB_DESKTOP.md` para entender cómo usar Git localmente.

### Paso 3: Configurar GitHub Copilot
Sigue `GUIA_GITHUB_COPILOT.md` para instalar la extensión en tu editor favorito.

### Paso 4: Crear tu Primera Lección
Dentro de la carpeta `mi-progreso/`, crea tu primer archivo de día 1.

## 💡 Consejos para Aprovechar al Máximo este Repositorio

1. **Haz commits diarios**: Cada día que aprendas algo nuevo, haz un commit con tu código
2. **Usa Copilot para refactorizar**: Cuando termines una función, pídele a Copilot que la mejore
3. **Crea issues para dudas**: Si tienes preguntas, crea una issue y Copilot puede ayudarte
4. **Revisa tu progreso**: Al final de cada semana, revisa lo que has aprendido
5. **Comparte tu progreso**: Si quieres, mantén el repo público para que otros vean tu evolución
